# DiGiga App

Mon second cerveau : projets, tâches, notes, CRM et objectifs (méthode PARA).

## Démarrer en local
1. Lancer **Docker Desktop**
2. `npm install`
3. `cp .env.example .env.local`
4. `npm run db:up && npm run db:migrate && npm run db:seed`
5. `npm run dev` → http://localhost:3000

Voir [ROADMAP.md](ROADMAP.md) pour la suite.
